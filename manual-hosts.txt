# 手动 pin 的 IP（每行 `IP 域名`，# 注释）
#
# 用途：你已经知道某个域名该用哪个 IP（比如实测最快的 CDN 边缘），直接钉死。
# 这个 IP 会被当成最高优先级候选，**但仍然要过 TLS 证书校验**：
#   - 校验通过 → 采用，状态记为 verified，来源 src=manual
#   - 校验失败 → 自动退回 DoH 现解析，不会写坏值
#
# 什么时候用：
#   - 某个域名的 DoH 解析结果总是不理想（拿到远端边缘）
#   - 你从别处（社区、自己抓包）确认了更优的 IP
#
# 示例（去掉行首的 # 才生效）：
#   23.45.136.230  steamcommunity.com
#   20.205.243.166 github.com
#   2a04:4e42::497 www.gog.com
